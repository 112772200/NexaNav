# NexaNav wordpress导航主题

一个简洁、美观、现代化的 WordPress 导航主题，适合搭建网址导航、资源导航、工具导航、AI 工具导航、设计导航、软件下载导航、个人收藏站等类型的网站。

NexaNav 注重移动端体验和内容展示效率，内置分类筛选、精选推荐、站内搜索、深色/浅色模式、友情链接展示等功能，可以帮助站长快速搭建一个清爽实用的导航站点。

## 功能介绍

### 首页导航展示

主题首页以导航内容为核心，可以展示多个站点、工具或资源条目。每个条目以卡片形式呈现，包含图标、标题、描述和访问入口，方便用户快速浏览和跳转。

### 分类筛选

支持通过分类按钮快速筛选站点内容。分类较多时，移动端支持展开和收起，保持页面简洁，同时兼顾完整浏览。

### 精选推荐

支持在首页展示重点推荐内容，适合放置常用站点、热门工具、推广资源或精选链接。

### 站内搜索

内置站内搜索入口，方便用户快速查找已收录的网站、工具或资源。

### 深色/浅色模式

主题支持深色模式与浅色模式，适合不同使用场景。用户可以根据自己的阅读习惯切换显示效果。

### 移动端适配

NexaNav 对移动端进行了适配，手机访问时会自动调整布局。顶部导航、搜索区域、精选内容、站点卡片和底部友情链接都针对小屏幕做了优化。

### 友情链接

首页支持底部友情链接展示，适合用于交换链接、展示合作站点或推荐相关资源。

### 图标兜底

当站点图标失效或无法加载时，主题会自动使用默认图标，避免页面出现破图，保持整体视觉统一。

## 安装方法

1. 下载发行版附件中的 `NexaNav-1.0.0.zip`
2. 登录 WordPress 后台
3. 进入 `外观` → `主题`
4. 点击 `安装主题`
5. 点击 `上传主题`
6. 选择 `NexaNav-1.0.0.zip`
7. 上传并启用主题

## 使用建议

安装主题后，建议先进入 WordPress 后台配置站点基础信息、导航分类、推荐内容和友情链接，再根据自己的站点类型调整内容。

如果你准备搭建一个导航站、资源站或工具收录站，NexaNav 可以作为一个轻量、直观、易维护的起点。
